#High Precision Microchip Failure Classification
##Project Overview
This project uses Machine Learning to classify microchips as functional or Defective.

##Algorithm used
-Support Vector Machine(SVM)
-RBF kernel

##Features
-Voltage Tolerence
-Thermal Stress

##Classes
-0=Functional
-1=Defective

##Technologies Used
-Python
-Pandas
-Numpy
-Scikit-learn
-Streamlit
-Matplotllib

##Project files
-'ui.py'-Streamlit application
-'microchip class.ipynb'-Jupyter notebook
-'microchip_data.csv'-Dataset
