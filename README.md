#High Precision Microchip Failure Classification

##Project Overview

This project uses Machine Learning to classify microchips as Functional or Defective.

##Algorithm Used -Support Vector Machine (SVM) -RBF kernel

##Features -Voltage Tolerence -Thermal Stress

##Classes -0=Functional -1=Defective

##Technologies Used -Python -Pandas -Numpy -Scikit-Learn -Streamlit -Matplotlib

##Project Files -'ui.py'-Streamlit application -'microchip class.ipynb'-Jupyter Notebook -'microchip_data.csv'-Dataset
